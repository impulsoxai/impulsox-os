# Copywriting Engine

> Verified: 2026-05-30. Re-verify creative limits live before launch.
> Limits: title recommended 16–24 / max 50 chars; copy recommended 32–48 / max 100 chars.

---

## Section 1 — Mother Rule: copy is conversation, not feed

Every ad here runs **inside a ChatGPT conversation**. The user is mid-task, asking
for help, leaning in. They are not scrolling a feed waiting to be interrupted. That
single fact governs all four layers below.

Three rules, in order:

1. **Useful > loud.** Read like a knowledgeable friend's recommendation, never a
   billboard. No `🔥`, no `AMAZING DEALS`, no ALL CAPS shouting.
2. **Specific > vague.** A number, a sensory detail, or a proper noun beats every
   adjective. "Wood-fired" beats "delicious."
3. **One idea only.** The title makes a single promise; the copy adds one new fact
   that pays it off. Stacking claims breaks trust and breaks the char limit.

**Why this channel is different:** in a feed, attention is stolen, so loud wins for
half a second. In a conversation, attention is already given — the user invited help
— so loud reads as intrusion and kills the very trust that makes them click. The ad
must continue the user's thought, not hijack it. Copy that sounds like an ad loses.
Copy that sounds like the answer they were already looking for wins.

## Section 2 — Layer 1: Frameworks compressed to fit

Five frameworks. Each is built for paragraphs; here you get **≤50 title / ≤100 copy**.
Compression rule of thumb: **keep the turn, cut the wind-up.** Name the friction or the
payoff and stop.

### PAS — Problem, Agitate, Solution
- **When to use:** the user already feels a pain and is looking to end it.
- **Compress:** title = the problem as a question. Copy = one line of relief (skip the
  agitation; the question already agitates).
- **Example:**
  - title: `Tired of waiting for a table?` (29)
  - copy: `Reserve your spot near Disney in 30 seconds, no line.` (53)
  - `framework_note`: `PAS — fixing/problem-aware`

### AIDA — Attention, Interest, Desire, Action
- **When to use:** the user is browsing options and you need to earn the click.
- **Compress:** title = Attention (a vivid noun phrase). Copy = Interest + Desire in one
  sentence; let the click be the Action.
- **Example:**
  - title: `Wood-fired pizza near Disney` (28)
  - copy: `Naples-style pies, blistered crust. Walk-ins seated nightly.` (60)
  - `framework_note`: `AIDA — exploring/unaware`

### BAB — Before, After, Bridge
- **When to use:** the user is stuck now and you can paint a fast "after."
- **Compress:** title = the Before. Copy = After + Bridge in one breath.
- **Example:**
  - title: `Hungry now, no plan?` (20)
  - copy: `Skip the food-court chaos. Sit down to fresh pasta in 10 min.` (61)
  - `framework_note`: `BAB — buying/solution-aware`

### 4U — Useful, Urgent, Unique, Ultra-specific
- **When to use:** a time-bound or specific offer where precision sells (Layer 2 maps both `planning/problem-aware` and `booking/most-aware` here — tone shifts from helpful next-step to frictionless action).
- **Compress:** load the title with the Ultra-specific + Unique hook; put Useful +
  Urgent in the copy. Numbers and named details carry all four U's.
- **Example:**
  - title: `Tacos & drinks till 11pm` (24)
  - copy: `Late-night al pastor 2 blocks from Universal. Order ahead.` (58)
  - `framework_note`: `4U — booking/most-aware`

### FAB — Feature, Advantage, Benefit
- **When to use:** the user is comparing and needs a concrete differentiator.
- **Compress:** title = the Feature stated plainly. Copy = Advantage + Benefit, made
  specific (counts, not claims).
- **Example:**
  - title: `Gluten-free menu, real options` (30)
  - copy: `12 GF dishes, not 1 sad salad. Celiac-safe kitchen, marked menu.` (64)
  - `framework_note`: `FAB — comparing/solution-aware`

## Section 3 — Layer 2: Consciousness decides the framework (the functional core)

**This is the layer that prevents generic copy. Do not skip it.** A framework chosen at
random produces "copy in general." A framework chosen by the user's awareness level
produces copy that meets them where they are.

The map is `user_state → Schwartz consciousness level → preferred framework → copy tone`.
Schwartz's five levels run from **Unaware** (doesn't know they have a problem) to
**Most Aware** (knows you, ready to act).

| user_state | Schwartz Level | Preferred Framework | Copy Tone |
|---|---|---|---|
| exploring | Unaware | AIDA | Inviting, curious — introduce, don't sell |
| planning | Problem-aware | 4U | Helpful, concrete — give a usable next step |
| comparing | Solution-aware | FAB | Even-handed, factual — show the real edge |
| fixing | Problem-aware | PAS | Reassuring, fast — name the pain, remove it |
| buying | Solution-aware | BAB | Confident, de-risking — justify the pick |
| booking | Most Aware | 4U | Direct, frictionless — make acting effortless |

**How to use it:** read the ad group's `user_state` → find its row → pick the **Preferred
Framework** as your default → confirm it fits the specific angle you're writing (if the
angle pulls toward a different framework, switch, but only deliberately) → write the ad
in the listed **Copy Tone** → record the choice in `framework_note` using the format
`FRAMEWORK — user_state/consciousness_level` (e.g. `PAS — fixing/problem-aware`). Every
ad carries this note, so every ad proves it passed through this layer.

## Section 4 — Layer 3: Cialdini triggers with ethical brakes

Persuasion triggers are allowed **only when the landing page proves the claim.** The LP
is the brake. If the LP can't show it, the ad can't say it.

### Social proof
- **Trigger:** cite real, countable evidence others chose you (ratings, review counts).
- **Ethical brake:** only if the LP (or a linked public profile) displays the exact
  figure.
- **OK example** — title `4.7 stars, 1,800+ reviews` (25) / copy
  `Orlando families rate our brunch 4.7 on Google. See for yourself.` (65). *Passes:* the
  Google rating is public and shown on the LP.
- **Prohibited:** `Best restaurant in the world` — unverifiable superlative, nothing for
  the LP to prove.

### Scarcity
- **Trigger:** flag genuine, time- or capacity-bound limits.
- **Ethical brake:** only if the limit is real and the LP/booking system reflects it.
- **OK example** — title `Patio books up by 7pm Fri` (25) / copy
  `Weekend patio fills fast. Reserve your sunset table early.` (58). *Passes:* the booking
  system shows the patio selling out — a real, observable limit.
- **Prohibited:** `Only 2 tables left forever!` — fake/manufactured urgency the LP can't
  substantiate.

### Authority
- **Trigger:** cite real, named credentials or expertise.
- **Ethical brake:** only if the LP documents the credential (bio, certification).
- **OK example** — title `Chef trained in Bologna` (23) / copy
  `Hand-rolled pasta daily by a Bologna-trained chef. Tasting menu.` (64). *Passes:* the
  chef's bio on the LP states the Bologna training.
- **Prohibited:** `Endorsed by OpenAI` — absolute policy violation, never use, and no LP
  could ever prove it.

### Reciprocity
- **Trigger:** offer something of real value up front (a free starter, guide, tasting).
- **Ethical brake:** only if the LP honors the exact offer.
- **OK example** — title `Free starter for first visit` (28) / copy
  `Show this ad: complimentary bruschetta on your first dinner.` (60). *Passes:* the LP /
  promo terms confirm the first-visit free starter.
- **Prohibited:** `Free dinner for everyone!` — an offer the business won't actually
  honor; the LP can't back it.

### Liking / affinity
- **Trigger:** show shared identity or warmth (family-run, local roots, community).
- **Ethical brake:** only if the affinity claim is true and reflected on the LP.
- **OK example** — title `Family-run since 2009` (21) / copy
  `Three generations, one kitchen near Disney Springs. Come say hi.` (64). *Passes:* the
  LP "About" page states the 2009 founding and family ownership.
- **Prohibited:** `We're basically your family` — empty, unprovable affinity with nothing
  concrete behind it.

**Hard prohibitions — never appear in any OK example or shipped ad:**
- `guaranteed` / `guarantee` — OpenAI policy violation, hard FAIL in the validator.
- `instant wealth` / `explosive growth` — hype/financial-claim violations, hard FAIL in the validator.
- `risk-free` / `risk free` / `100% guaranteed` — absolute-promise violations, hard FAIL in the validator.
- `endorsed by OpenAI` / `OpenAI recommends` — absolute policy violation.
- Any claim the landing page cannot prove — if in doubt, cut it.

## Section 5 — Layer 4: Specific beats hype (Ogilvy operationalized)

**Hard rule:** a number, a sensory detail, or a proper noun **always** beats a vague
adjective. Hype is what you write when you don't know the specific. Find the specific.

| Hype (avoid) | Specific (use) |
|---|---|
| Amazing pizza | Wood-fired, 90-second Neapolitan crust |
| Great reviews | 4.7 stars, 1,800+ Google reviews |
| Conveniently located | 2 blocks from Universal's main gate |
| Huge portions | 14 oz hand-cut ribeye |
| Authentic Italian | Pasta hand-rolled daily by a Bologna chef |
| Open late | Kitchen open till 11pm, 7 nights |
| Affordable family meal | Kids eat free before 6pm |

**Self-test:** replace your adjective with a number or a named detail. If the ad gets
**more concrete**, the replacement wins — keep it. If you can't find a number or name to
swap in, you don't yet understand the offer well enough to write the ad; go get the fact.

## Section 6 — Step 6 output spec

For each ad group, produce **8 ad variations**, one per angle, covering all eight:
`pain`, `use_case`, `comparison`, `outcome`, `speed`, `proof`, `cost`, `risk_reduction`.

Each ad object must contain:
- `angle` — one of the eight above.
- `framework_note` — format `FRAMEWORK — user_state/consciousness_level`
  (e.g. `BAB — buying/solution-aware`).
- `title` — ≤50 chars (aim 16–24).
- `copy` — ≤100 chars (aim 32–48), adding one new fact the title didn't state.

> Serialization (how these ad objects are assembled into the canonical `campaign-plan.json`) is owned by `SKILL.md`. This reference defines only what each ad must contain, not its output format.

**Process for every single ad (run all steps, in order):**
1. Read the ad group's `user_state`.
2. Go to the **Layer 2 table**, find that row, take the **Preferred Framework** and
   **Copy Tone**.
3. Confirm the framework fits this ad's `angle`; switch only if deliberate, then note it.
4. Draft title + copy using the **Layer 1** compression rules for that framework.
5. Check any persuasion trigger against the LP (**Layer 3**) — if the LP can't prove it,
   cut or replace the claim.
6. Run the **Layer 4** specificity check — swap every vague adjective for a number,
   sensory detail, or proper noun.
7. **Policy gate:** reject `guaranteed`/`guarantee`, `endorsed by OpenAI`/
   `OpenAI recommends`, emojis, and any unprovable claim. Re-count chars: title ≤50,
   copy ≤100.
8. Record `framework_note`, then move to the next angle.

Skipping any step degrades the output to generic copy. Run all eight, every time.
