# Referências premiadas por nicho — acervo curado da agência

> Os 3 melhores sites do mundo de cada nicho, pro cliente escolher o ESTILO (não a marca).
> Consumido pela `/premium-design` (Uso 3): mostra essas 3 ao cliente → ele escolhe o jeito →
> a skill re-estiliza o design dele naquele nível, com a identidade do cliente CRAVADA.
>
> **Como cresce:** nicho que não está aqui → a skill pesquisa na hora (Awwwards, Godly,
> Landbook, SiteInspire por nicho) e GRAVA as 3 melhores aqui pra reusar. Cada cliente
> enriquece o acervo. É ativo da agência — o que justifica cobrar nível posicionamento (10k+),
> não nível "site bonito" (5k).
>
> **Regra:** daqui sai só o ESTILO (estrutura, ritmo, animação, sofisticação). NUNCA a cor,
> fonte ou marca do site de referência — a identidade é 100% do cliente (regra do CLAUDE.md).
>
> Formato de cada nicho: 3 URLs + 1 linha do que cada uma faz bem (o diferencial a capturar).
> Validar a URL antes de mostrar (sites premiados saem do ar) — link morto, pesquisar substituto.

## Como usar (na reunião com o cliente)

1. Identificar o nicho do cliente (do `nucleo/negocio.md` ou perguntar).
2. Achar o nicho abaixo. Não existe? Pesquisar os 3 melhores e gravar aqui.
3. Capturar as 3 (Fase 1) e mostrar ao cliente: **"Estes são os 3 melhores sites de [nicho]
   do mundo. Qual desse estilo você quer pro seu? Eu faço no mesmo nível, mas com a SUA cara."**
4. Cliente escolhe → Uso 3 re-estiliza o design dele naquele jeito.
