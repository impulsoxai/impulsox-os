# Glossário de transcrição — termos da marca (EXEMPLO/TEMPLATE)

> Lido pelo `editar-video.mjs` e aplicado na transcrição do whisper ANTES de montar a
> legenda (.srt + karaokê). Conserta termos que o whisper foneticiza errado (estrangeirismos,
> nome da marca). Uma regra por linha: `errado => certo`. Caixa do "errado" é ignorada
> (case-insensitive); o "certo" entra como está. Palavra inteira só (não pega substring).
> Linha começando com # é comentário.
>
> As regras abaixo são EXEMPLOS comuns. Acrescente os termos do SEU nicho/marca (nome da
> empresa, jargões, estrangeirismos que você usa).

real => reel
reals => reels
you tube => YouTube
inflhistory => in real life
# exemplo de nome de marca: cloud x => CloudX
