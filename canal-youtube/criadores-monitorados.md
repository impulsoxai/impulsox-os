# Criadores monitorados — radar de formato (EXEMPLO/TEMPLATE)

> **Template.** Substitua pelos criadores do SEU nicho. Lido pelo `checar-criadores-yt.mjs`.
> RSS público, sem API key, sem login:
> `https://www.youtube.com/feeds/videos.xml?channel_id=<Channel ID>`. Linha sem Channel ID
> válido (`UC` + 22 caracteres) é ignorada pelo monitoramento até ser resolvida — use
> `scripts/resolver-canal-yt.mjs @handle` pra descobrir o Channel ID a partir do @handle.
